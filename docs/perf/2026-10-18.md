# P374 efficiency pass (Oct 18)

Measured with `questcheck --perfscenes --rd 12 --only camp,gulch` (spots added for the forest bandit camp and Stone
Gulch), host x86 build with the headset's flags (`-Ounchecked -wmo -enforce-exclusivity=unchecked`), GPU commands
dropped (lavapipe is not an Adreno). Times are the main thread's per-frame ms standing still for 5 s.

## Before (quest-port 00caee42)
| scene | tick | record | top costs |
|---|---|---|---|
| Stone Gulch | 0.71 | 2.07 | mob drawing 0.92, culling 0.66, random ticks 0.24, mob AI 0.23 |
| bandit camp | 0.61 | 0.98 | culling 0.48, random ticks 0.27, terrain 0.16, mob drawing 0.15 |

Memory at Stone Gulch: resident 1041 MB; 593 chunks hold blocks 52 MB, ground field 50 MB, light 21 MB; mesh 60 MB;
textures 1219 layers at 128 px, ~106 MB with mips. Every chunk written between autosaves (random ticks, flows, edits)
kept a second copy of its blocks and field until the next save (`savedBlocks`), up to the whole loaded block memory again.

APK: 273 MB (309 MB unpacked): recorded sounds 118 MB (912 WAVs), music 88 MB (40 m4a), native libraries 80 MB
(libblocksmith.so 67 MB), texpack 18 MB, voices 5 MB.

## Fixes
1. Mob drawing: each part's distinct points are placed once (8 box corners, 24 bevel points) instead of per triangle
   corner; the rounded parts' tables are read once per frame.
2. Far landmarks: an empty build no longer repeats every frame; standing still it rebuilds every half second.
3. Random ticks: each chunk keeps its highest column (`Chunk.heightMax`) instead of scanning 256 columns per tick.
4. Memory: chunks keep an `unsaved` flag instead of the last-saved arrays, so no second copy is held.

## After (Stone Gulch, measured while another build ran: slightly noisy)
tick 0.83 (mob AI 0.35, random ticks 0.24), record 1.56 (mob drawing 0.49, culling 0.59, landmarks 0.11);
resident 888 MB, save copies 0 MB.

## Left
- Culling (0.6 ms) is unchanged: limiting the P335 neighbour peeks dropped ~190 far sections, not shipped untested.
- The headset's own frame time and GPU cost at the camp (45-53 fps in the notes) need a device measurement; the
  camp draws 141k quads (37k of them leaf blobs).
- APK size not reduced (WAV sounds are the largest part).
