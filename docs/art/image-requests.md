# Blocksmith image requests (IMG1)

Every image the game still wants, one line each, for Remington's Gemini account (gemini.google.com image generation).
Written 2026-10-14 from the working tree at `d2731fab` (including uncommitted work: `Sources/Spine.swift` adds the last three readables). Nothing here is generated yet. The Mac drops the results in and imports them.

## How to use

1. **Start each Gemini chat with the style.** Upload the style reference image `docs/art/style-options/3-stylised-realism.png`
   and paste the [Shared style](#shared-style-s1) paragraph once. Then paste one row's prompt per message. Keep using the same
   reference image all the way through, so the whole set matches.
2. **Generate at 1024 px or larger, square unless the row says otherwise.** The importers downsample: block faces to 128 px,
   plant sprites and item icons to 64 px. You don't need to hit the final size.
3. **Name the file exactly as the row's *drop as* path** (lower case, underscores, `.png`; JPEG is fine for icons and plants).
   The name is the game's internal texture name (a save ID), not the player-facing name. Never rename it.
4. **Drop it in that path on the Mac** (`assets/gemini/...` in the repo) and commit. The Mac then imports it:
   - block faces (`tile`, `face`, `cut`, `flat`): `python3 tools/teximport.py assets/gemini/<name>.png <name> --mode plain|cutout --out Resources/Textures`
     (square crop, 2x2-repeat check, brightness flattening, colour lock, wrap-aware downsample to 128 px, seam check and
     cross-fade; `cutout` keys out the magenta). Trial first with `--out build/texgen/out` and `./snap.sh --texdir build/texgen/out`.
   - plant sprites and item icons: add a one-cell entry (`"grid": 1`) to `docs/textures/plants.json` or `docs/textures/icons.json`
     and run `python3 tools/iconslice.py [--spec docs/textures/plants.json] --only <file>`: magenta key, de-spill, fit to 64 px
     (plants stand on the bottom edge, hard alpha). Output `Resources/Textures/<name>.png` or `item_<name>.png`.
   - paintings: copy to `Resources/Textures/painting_<key>.png` as they are (do **not** run teximport: it crops to a square).
     The game box-filters any size to the 128 px layer and stretches it back over the painting's w x h blocks.
   - posters, shop signs and UI art: no loader reads them yet (each row says *needs a code hook*). Drop them in the path; a
     code task wires them up.
   - after any import: `python3 tools/texpack.py` repacks `Resources/texpack.bin` for the Quest (once per batch, not per file),
     and the prompt goes verbatim into `assets/CREDITS.md` (rule AR7).
5. **Batching is allowed.** The existing pipeline also slices 4x4 sheets (`tools/sheetslice.py`, `tools/iconslice.py`). If Gemini
   is faster with sheets, put 16 rows of the same family in one 4x4 prompt and add a sheet entry in the matching json instead.
6. **Check, then adopt.** Compare each import with the procedural one (`./snap.sh ... --procedural` vs the default) before it
   stays. A file in `Resources/Textures` replaces that layer's procedural art in the Mac build (Sources/TextureImport.swift) and,
   through texpack.bin, on the Quest (quest/src/common/QuestTextureImport.swift).

Column **mode**: `tile` seamless repeating face; `face` one face that need not repeat (a machine front, a lid); `cut` a face with
see-through parts painted magenta; `flat` ground cover from above on magenta; `plant` a sprite standing on the bottom edge;
`hang` a sprite hanging from the top edge; `sheet` one image cut into several layers.

## Shared style (S1)

> Blocksmith art direction is **style 3, stylised realism** (picked by Remington 2026-10-09; `docs/textures/STYLE_GUIDE.md`,
> reference `docs/art/style-options/3-stylised-realism.png`). Real-world materials, simplified; subtle surface detail; natural,
> moderately saturated earthy palette; a soft hand-painted look with crisp readable shapes; one soft light from the top-left
> as gentle relief, no cast shadows, no specular glare. NOT pixel art, NOT cartoon, NOT a photograph. Square, straight-on,
> orthographic for block faces. Features sized for the block: about 4-12 main elements across a tile, never hundreds. Uniform
> density, no big light or dark patches, no vignette. No text, letters, numbers, logos, borders or watermarks anywhere. Every
> design is original Blocksmith art: never copy or imitate another game's textures, characters or logos.

Family references used in the *style* column:

- **S2 block faces**: S1, plus seamless on all four edges for `tile`; 1024 px source, 128 px in game.
- **S3 cutouts and sprites**: S1, plus a perfectly flat pure magenta `#FF00FF` background with hard edges (the importer keys it
  out); plants centred, standing on the bottom edge or hanging from the top edge, no ground, no shadow; 64 px in game.
- **S4 item icons**: S1, three-quarter view, centred at about 80% of the cell, on flat magenta; 64 px in game. Match the 503
  styled icons in `Resources/Textures/item_*.png` (sheets i01-i25 in `assets/gemini/icons`).
- **S5 pictures** (paintings, posters, signs): S1's palette and brushwork, but a picture: framed composition, painterly, readable
  at very low resolution (a 4x4-block painting has only 128 x 128 texels), big simple shapes, strong silhouettes, no lettering.
- **S6 UI and store art**: S1's palette; scenes are built from cube-shaped blocks like the game; leave calm space where the
  game prints text.
- Per-family notes (F-...) are given under each family heading below.
